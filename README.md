# Cambio-climatico
Repositorio del cambio climático
## Esta es la idea de mi proyecto:
> Mi idea para mi proyecto es crear una app que use la cámara para identificar y clasificar residuos. Escanearía la imagen y daría una recomendación de que hacer con el objeto y un porcentaje de confianza. Pienso en primeramente hacerlo con cosas sencillas como papel, carton, plástico, vidrio y residuos orgánicos y luego hacerlo con cosas que requieran manejos específicos
## Esta es lo que usaré:
> Usaré google teachable machine para entrenar un modelo que escanee las imágenes y de recomendaciones según lo que vea
